# Как получить приложение на iPhone, имея только Windows

Собирать iOS-приложение умеет только macOS. Мака у нас нет — поэтому собирает
**GitHub Actions**: облачный Mac, бесплатный для публичных репозиториев.
Результат — файл `.ipa`, который ставится на телефон через **Sideloadly** прямо с Windows.

```
я правлю код  →  ты пушишь в GitHub  →  облачный Mac собирает и прогоняет тесты
                                              ↓
                        зелено: скачиваешь .ipa  →  Sideloadly  →  iPhone
                        красно: присылаешь мне лог ошибки  →  я чиню  →  повтор
```

---

## Шаг 1. Создать репозиторий (один раз)

1. Зайди на github.com → **New repository**.
2. Имя: `LinguaQuest`. Тип: **Public** — на публичных репозиториях минуты macOS бесплатны.
   На приватном они платные (macOS-минута стоит примерно как 10 обычных).
3. **Не** добавляй README/gitignore — они уже есть в проекте.

## Шаг 2. Залить код (один раз)

Установи [Git для Windows](https://git-scm.com/download/win), открой PowerShell в папке проекта:

```powershell
cd "D:\CLAUDE Code\PROJECTS\LinguaQuest"
git init
git add .
git commit -m "LinguaQuest: спринты 0-1"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/LinguaQuest.git
git push -u origin main
```

Проверка сборки запустится сама. Вкладка **Actions** покажет результат.

## Шаг 3. Получить .ipa

1. Вкладка **Actions** → слева **«Сборка IPA для телефона»** → кнопка **Run workflow** → зелёная **Run workflow**.
2. Через 5–10 минут открой завершившийся запуск.
3. Внизу в разделе **Artifacts** скачай `LinguaQuest-ipa` — внутри `LinguaQuest-unsigned.ipa`.

## Шаг 4. Установить на iPhone через Sideloadly

Понадобится один раз:

- [Sideloadly](https://sideloadly.io) для Windows
- **iTunes и iCloud, скачанные с сайта Apple** (не версии из Microsoft Store — Sideloadly их не видит)
- кабель для первого подключения

Дальше:

1. Подключи iPhone кабелем, разблокируй, нажми «Доверять этому компьютеру».
2. Открой Sideloadly, перетащи в него `LinguaQuest-unsigned.ipa`.
3. Введи свой **обычный Apple ID** (платный аккаунт не нужен) и нажми **Start**.
   Apple попросит пароль от приложения, если включена двухфакторка — создай его
   на appleid.apple.com в разделе безопасности.
4. На телефоне: **Настройки → Основные → VPN и управление устройством** → выбери свой
   Apple ID → **Доверять**. Без этого приложение не запустится.

Приложение появится на домашнем экране.

### Что нужно знать про бесплатную подпись

| Ограничение | Значение |
|---|---|
| Срок жизни приложения | **7 дней**, потом оно перестаёт открываться |
| Как продлить | Переустановить тем же способом (прогресс в приложении сохраняется, если не удалять его вручную) |
| Сколько приложений одновременно | 3 |
| Нужен ли компьютер | Да, для установки и продления |

Платный Apple Developer Program ($99/год) снимает всё это: приложение ставится
через TestFlight, живёт 90 дней, обновления прилетают сами — но это уже когда
надоест переустанавливать раз в неделю. Переключение делается добавлением
сертификатов в секреты репозитория, код при этом не меняется.

---

## Шаг 5. Цикл правок

Когда я вношу изменения:

1. Я отдаю обновлённые файлы, ты копируешь их в папку проекта.
2. ```powershell
   git add .
   git commit -m "что изменилось"
   git push
   ```
3. Смотришь **Actions**:
   - **зелёная галочка** — можно запускать сборку IPA и ставить на телефон;
   - **красный крест** — открой упавший запуск, в разделе **Summary** будет блок
     «Ошибки сборки». **Скопируй его мне целиком** — этого достаточно, чтобы я починил.
     Если блока нет, скачай артефакт `build-logs`.

Присылай и просто наблюдения после теста на телефоне («шрифт мелкий», «сердца
тратятся не так») — это нормальная часть цикла, ради него всё и затевается.

## Если что-то идёт не так

| Симптом | Причина и что делать |
|---|---|
| Sideloadly не видит iPhone | Установлены iTunes/iCloud из Microsoft Store. Удалить, поставить версии с apple.com |
| «Untrusted Developer» при запуске | Не выполнен шаг с «Доверять» в Настройках |
| Приложение перестало открываться | Прошло 7 дней — переустановить через Sideloadly |
| Actions пишет про лимит минут | Репозиторий приватный. Переключить в Public в Settings |
| Сборка падает на `xcodegen` | Прислать мне лог — почти наверняка правка в `project.yml` |
