# Пайплайн генерации учебного контента

Раздел 5A ТЗ в рабочем виде: как появляются уроки, что запрещено и как проверить результат.

## Правило по копирайту

Контент **не копируется** из учебников, курсов и других защищённых источников.
Упражнения и объяснения пишутся оригинально, опираясь на **открытые стандарты**:

| Источник | Что берём | Статус |
|----------|-----------|--------|
| CEFR Companion Volume (Council of Europe) | дескрипторы уровней, «can-do» формулировки | открытый документ |
| Oxford 3000 / 5000 | частотный список ядровой лексики | открытый список слов |
| NGSL | ~2800 самых частотных слов | открытая лицензия |
| English Grammar / Vocabulary Profile | что усваивается на каждом уровне | открытые ресурсы |

Берётся **тема и словарный срез**, а предложения пишутся заново.
Каждый файл навыка обязан указывать `sourceStandard` — это след для аудита.

## Шаги

1. Взять дескриптор CEFR по теме (например A1: «Present Simple, повседневная рутина»).
2. Взять срез частотного списка под уровень.
3. Сгенерировать N оригинальных упражнений по схеме ниже, с нарастающей сложностью (`difficulty` 1→3).
4. Второй проход: проверить уровень, корректность английского, отсутствие дублей и неоднозначных ответов.
5. Ручная вычитка разработчиком.
6. `python3 Tools/validate_content.py` — машинная проверка схемы.
7. Добавить файл в `manifest.json` и поднять `contentVersion`.

## Куда класть файлы

```
Packages/LinguaQuestKit/Sources/ContentModels/Resources/Content/
  manifest.json              список файлов + версия контента
  vocabulary.json            словарь для SRS
  skill_<key>.json           один файл на навык
```

В Фазе 2 те же структуры переезжают в Firestore — форматы совпадают намеренно.

## Схема навыка

```jsonc
{
  "skillKey": "present_simple_a1",       // уникален во всём каталоге
  "cefrLevel": "A1",
  "category": "grammar",                  // grammar | vocab | listening | speaking
  "title": "Present Simple",
  "subtitle": "Повседневные действия",
  "iconName": "clock.arrow.circlepath",   // SF Symbol
  "prerequisiteKeys": ["greetings_a1"],   // что открыть до
  "sourceStandard": "CEFR ... + Oxford 3000",
  "lessons": [
    {
      "lessonId": "ps_a1_l1",
      "title": "Я и ты: базовая форма",
      "orderIndex": 1,
      "xpReward": 20,
      "exercises": [ /* см. ниже */ ]
    }
  ]
}
```

## Типы заданий

Реализованы в Спринте 1: `multiple_choice`, `type_answer`, `match_pairs`.
Остальные типы можно писать заранее — загрузчик отфильтрует их, пока
`ExerciseType.isImplemented` возвращает `false`.

```jsonc
// multiple_choice — correctAnswer обязан присутствовать среди options
{
  "id": "ps1_e1",
  "type": "multiple_choice",
  "prompt": "She ___ coffee every morning.",
  "correctAnswer": "drinks",
  "options": ["drink", "drinks", "drinking"],
  "hint": "Третье лицо единственного числа",
  "explanation": "После he/she/it глагол получает -s.",
  "difficulty": 1,
  "vocabularyIds": ["v_drink", "v_coffee"],
  "errorCategory": "tense"
}

// type_answer — регистр и пунктуация игнорируются, одна опечатка прощается
{
  "id": "g1_e3",
  "type": "type_answer",
  "prompt": "Переведите: до свидания",
  "correctAnswer": "goodbye",
  "acceptedAnswers": ["good bye", "bye"]
}

// match_pairs — правые части обязаны быть различны, иначе ответ неоднозначен
{
  "id": "g1_e4",
  "type": "match_pairs",
  "prompt": "Соедините слова с переводом",
  "pairs": [
    { "id": "p1", "left": "hello", "right": "привет" },
    { "id": "p2", "left": "goodbye", "right": "до свидания" }
  ]
}
```

## На что смотреть при вычитке

- **Однозначность.** У задания ровно один правильный ответ. Частая ловушка — дистрактор,
  который тоже грамматически верен вне контекста.
- **Уровень.** В задании A1 не должно быть лексики и конструкций выше уровня.
- **Ошибка учит.** `explanation` объясняет правило, а не повторяет ответ.
- **`errorCategory`.** Заполняйте честно (`tense`, `spelling`, `articles`, `word_order`,
  `negation`, `question_form`, `vocabulary`) — на этих данных в Фазе 2 строится адаптивность.
- **`vocabularyIds`.** Только из `vocabulary.json`: по ним создаются карточки SRS.
- **Прогрессия.** Порядок показа заданий задаёт поле `difficulty` (1→3):
  `ContentCatalog.orderedByDifficulty` сортирует их при загрузке, сохраняя
  исходный порядок внутри одной сложности. Следить за очерёдностью в файле не нужно —
  достаточно честно проставить `difficulty`.

## Проверка

```bash
python3 Tools/validate_content.py
```

Валидатор ловит: сломанный JSON, отсутствующие поля, ответ вне вариантов,
дубликаты id, неоднозначные пары, ссылки на несуществующие слова,
недостижимые навыки, циклы в предпосылках и неиспользуемую лексику.
Те же правила продублированы в `ContentCatalogTests` — контент проверяется и на сборке.
