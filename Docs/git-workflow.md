# Как мы работаем через GitHub

Короткая памятка о том, кто что делает. Полная инструкция по установке на телефон —
в [`deploy-to-iphone.md`](deploy-to-iphone.md).

## Разделение ролей

| Действие | Кто | Почему так |
|---|---|---|
| Написать и поправить код | я | |
| Положить файлы в папку проекта | я | напрямую, через подключённую папку |
| `git commit` и `git push` | ты | у меня нет доступа к твоему аккаунту GitHub |
| Посмотреть, упала ли сборка и почему | я | CI кладёт выжимку ошибок в сам репозиторий, её видно без авторизации |
| Скачать `.ipa` и поставить на телефон | ты | |

**Токен доступа присылать мне не нужно.** Секреты в переписке — плохая идея в любом
случае, а здесь ещё и не нужны: чтобы читать публичный репозиторий и результаты сборки,
авторизация не требуется.

## Первый запуск (один раз)

1. Создай на github.com **публичный** репозиторий `LinguaQuest`
   (публичный — потому что на нём macOS-минуты бесплатны).
2. В PowerShell в папке проекта:

   ```powershell
   cd "D:\CLAUDE Code\PROJECTS\LinguaQuest"

   # если git ругается на index.lock — удалить оставшиеся локи:
   Remove-Item .git\*.lock -Force -ErrorAction SilentlyContinue
   Get-ChildItem .git\objects -Recurse -Filter "tmp_obj_*" | Remove-Item -Force

   git remote add origin https://github.com/ТВОЙ_ЛОГИН/LinguaQuest.git
   git push -u origin main
   ```

   При первом push откроется браузер для входа в GitHub — данные останутся у тебя,
   Windows запомнит их и больше спрашивать не будет.

3. Пришли мне ссылку на репозиторий.

## Дальше, на каждой итерации

Я говорю, что поменял. Ты:

```powershell
cd "D:\CLAUDE Code\PROJECTS\LinguaQuest"
git add .
git commit -m "что изменилось"
git push
```

Через 5–15 минут я сам смотрю `ci-status/last-build.md` в репозитории и вижу:
сборка зелёная — или список ошибок компиляции. Копировать логи вручную не нужно.

Если сборка зелёная — Actions → «Сборка IPA для телефона» → Run workflow → скачиваешь
артефакт и ставишь через Sideloadly.

## Полезные команды

```powershell
git status          # что изменилось локально
git log --oneline -5    # последние коммиты
git pull            # забрать записанный CI результат (ci-status/)
```

`git pull` пригодится: CI сам коммитит файл с результатом сборки, поэтому перед
следующим push иногда нужно сначала подтянуть его изменения.
