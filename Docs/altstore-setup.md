# AltStore: установка без провода и автопродление подписи

AltStore Classic — бесплатный инструмент с открытым кодом. Он решает главное неудобство
бесплатной подписи: **сам продлевает её в фоне**, пока компьютер с AltServer включён
и телефон в той же Wi-Fi сети. Раз в неделю переустанавливать приложение больше не нужно.

Что остаётся за компьютером: установка новой версии, когда я её выпускаю.
Но уже без кабеля — по Wi-Fi.

---

## Перед началом

Часть шагов уже сделана при работе с Sideloadly, проверь только это:

- **iTunes и iCloud установлены с сайта Apple**, а не из Microsoft Store
  (`https://www.apple.com/itunes/download/win64`)
- iPhone «доверяет» компьютеру
- **Режим разработчика включён** (Настройки → Конфиденциальность и безопасность)

## Важно про переход с Sideloadly

Приложение поставится поверх — идентификатор и подпись те же, прогресс должен сохраниться.
Но если iOS откажется устанавливать поверх, придётся удалить старую версию,
**и тогда прогресс обнулится**. Сейчас в приложении накоплено немного, так что момент
для перехода удачный — позже это будет обиднее.

---

## Шаг 1. Установить AltServer на компьютер

1. Скачать **AltServer для Windows** с [altstore.io](https://altstore.io).
2. Распаковать архив, запустить `Setup.exe`.
3. Запустить AltServer **от имени администратора** (правой кнопкой по значку).
   Разрешить доступ к сети, когда попросит Windows.

Значок AltServer появится в трее — в правом нижнем углу, возможно под стрелкой «показать
скрытые значки».

## Шаг 2. Установить AltStore на телефон

1. Подключить iPhone кабелем, **разблокировать** экран.
2. В iTunes выбрать устройство и включить **«Синхронизировать по Wi-Fi»** —
   без этого пункта беспроводная работа не заведётся.
3. Нажать на значок AltServer в трее → **Install AltStore** → выбрать свой iPhone.
4. Ввести Apple ID и пароль. Они уходят напрямую в Apple — AltServer их не хранит.
   При включённой двухфакторной аутентификации понадобится пароль приложения
   (создаётся на `appleid.apple.com` в разделе безопасности).
5. Дождаться уведомления об успехе.
6. На телефоне: **Настройки → Основные → VPN и управление устройством** →
   выбрать свой Apple ID → **Доверять** (подтвердить дважды).

На домашнем экране появится AltStore.

## Шаг 3. Включить фоновое обновление

1. Открыть **AltStore** на телефоне → вкладка **Settings**.
2. Убедиться, что включён **Background Refresh**.

С этого момента AltStore будет сам будиться и продлевать подпись, пока AltServer запущен.
Чтобы это работало без напоминаний, стоит добавить AltServer в автозагрузку Windows.

## Шаг 4. Поставить LinguaQuest

Кабель уже можно отключить — дальше всё по Wi-Fi, пока телефон и компьютер в одной сети.

1. Скачать свежую сборку на компьютер:
   `https://github.com/AndriiXp/LinguaQuest/releases/download/latest/LinguaQuest.ipa`
2. Значок AltServer в трее → **Sideload .ipa** → выбрать устройство → выбрать скачанный файл.
3. Дождаться уведомления. Приложение появится или обновится на телефоне.

## Как это будет выглядеть дальше

| Событие | Что делать |
|---|---|
| Прошла неделя | ничего — AltStore продлил подпись сам |
| Я выпустил новую версию | скачать `.ipa` по ссылке выше, AltServer → Sideload .ipa |
| Компьютер был выключен дольше недели | открыть AltStore на телефоне и нажать **Refresh All** при включённом AltServer |

## Если что-то не так

| Симптом | Причина |
|---|---|
| AltServer не видит iPhone | не включён Wi-Fi sync в iTunes, либо устройства в разных сетях |
| «Не удалось обновить» в AltStore | AltServer не запущен или компьютер спит |
| Приложение перестало открываться | подпись истекла: запустить AltServer, в AltStore нажать Refresh All |
| «Не осталось слотов» | занято 3 приложения: в AltStore можно **деактивировать** одно — данные сохранятся |

## Границы возможного

Полностью без компьютера умеет работать **SideStore** — форк AltStore, который
переподписывает приложения прямо на устройстве. Но его настройка заметно сложнее:
нужен файл сопряжения и VPN-профиль на телефоне, и всё это чаще ломается
при обновлениях iOS. Смысл в нём появляется, если компьютер обычно выключен.

Совсем без этих плясок работает только TestFlight — но он требует
Apple Developer Program за $99 в год.
